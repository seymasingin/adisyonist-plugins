# Adisyonist

Adisyonist MCP bağlantısı, kullanım skill'i ve üç komut. Ayrıntılar için [ana README](../../README.md).

- `.claude-plugin/plugin.json` – eklenti tanımı
- `.mcp.json` – MCP sunucu bağlantısı (`https://mcp.adisyonist.com/mcp`)
- `skills/adisyonist/SKILL.md` – araç kullanım kılavuzu ve iş akışları
- `commands/` – slash komutları
